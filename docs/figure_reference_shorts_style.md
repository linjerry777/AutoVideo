# 名人解析 Reference Shorts 風格流程

參考目標：高留存的「名人原片 + 大標題 + 中英字幕 + 來源 + 品牌欄」Shorts。

## 1. 選片

- 優先挑訪談、演講、podcast 片段。
- 人臉必須是畫面主訊號。若原片人物太小，使用 face-aware crop 自動放大，不直接排除。
- 片段長度以 25-55 秒為主。能拆多段就拆多段，盡量把長片用滿。
- 只排除嚴重問題：無法聽清楚、字幕整段錯位、主角完全不在畫面、畫質糊到無法辨識。
- 輕微 ASR 錯字保留，後續用人工/規則校正字幕。

## 2. 裁切

- 先下載原始橫式片段。
- 用 OpenCV 抽樣偵測臉部位置。
- 依照主要臉部中心偏移 9:16 裁切。
- 若臉太小，自動加 zoom，最多 2.1 倍。
- 偵測失敗時才 fallback 中心裁切。

## 3. 版型

- 1080x1920 黑底。
- 上方固定兩行大標：
  - 第一行黃色，製造問題或衝突。
  - 第二行白色，補完懸念。
- 中間放原片大畫面，重點是臉與表情。
- 字幕放在原片下緣內，不壓到底部品牌欄。
- 原片下方顯示 source credit。
- 底部固定 DORO 品牌欄，建立系列辨識。

## 4. 字幕

- 中文字幕比英文大。
- 英文保留在中文下方，作為可信度輔助。
- 只修會影響理解的 ASR 錯字。小瑕疵不淘汰片段。
- 中文翻譯不逐字硬翻，優先讓觀眾秒懂。

## 5. 節奏

- 不做複雜轉場，避免分散注意力。
- 用人物臉、字幕節奏、標題問題撐住觀看。
- 每 6-10 秒至少要有一句「能單獨成立」的字幕。
- 原片本身有停頓時，可用輕微 zoom/crop 變化處理，避免靜止感。
